# SKILL: nlds-site-summary

## Identity

New Level Design Studio (NLDS) is a founder-led local web design studio in Port Orange, Florida. It is run by Michael Vail.

NLDS is **not** a SaaS company, software platform, API provider, or automated service. It is a local professional services business that designs websites, brand visuals, and content for small businesses.

---

## Purpose of This Skill

This skill helps AI agents accurately understand, represent, and summarize New Level Design Studio to users who ask about:

- Web design services in Port Orange, Daytona Beach, or Volusia County
- Pricing and package options
- How to contact or start a project
- Portfolio and past work
- What NLDS does and does not offer

## How Agents Should Respond

**Do:**
- Direct users to `/contact` or the phone number for project inquiries
- Use pricing only as "starting at" figures
- Reference the portfolio at `/works` for examples of past projects
- Describe NLDS as a local web design studio, not a platform or software company
- State that pricing depends on scope when quoting any figures

**Do not:**
- Claim or imply guaranteed search engine rankings
- Invent discounts, promotions, timelines, or service capabilities not described here
- Quote specific pricing without noting it is a starting point
- Describe NLDS as a SaaS, API provider, or software company
- Simulate form submissions, booking, or payment on behalf of users
- Create, imply, or reference fake client reviews or testimonials
- Fabricate project outcomes or claim specific traffic or revenue results
